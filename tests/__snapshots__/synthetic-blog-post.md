# Why plain files beat apps

![](https://blog.example.com/images/plain-files-cover.png)

Apps come and go. *Files* stay. If your notes are plain `.md` files, any editor can open them, and you can move to another tool in an afternoon.[^1]

> The files you create are more important than the tools you use to create them.

## A small example

Here is the whole idea in a few lines:

```js
const note = { title: 'Hello', body: 'World' };
console.log(note.title);
```

### Checklist

1. Pick a folder
2. Write in Markdown
3. Back it up

| Format | Readable in 10 years? |
| --- | --- |
| Markdown | Yes |
| Proprietary database | Unclear |

[^1]: Assuming you keep a copy somewhere safe.
